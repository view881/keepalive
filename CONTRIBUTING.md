# Contributing

Keepalive welcomes three kinds of help:

1. **Nominate a tool.** Open an issue with the repository, who depends on it, and evidence of decay. Verified deployment counts (a clinic, school or cooperative confirmed to run it) are especially valuable.
2. **Improve the Index.** Propose better signals or fix bias in [docs/METHODOLOGY.md](docs/METHODOLOGY.md). Back changes with examples.
3. **Maintain.** If you live in a region that depends on a nominated tool and want to be a paid maintainer, open an issue.

Code changes: fork, branch, add tests, run `pytest`, open a pull request. Be kind. Be specific.

Never post private information about people or organisations running a tool.
